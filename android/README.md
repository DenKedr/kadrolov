# Кадролов для Android

Локальные снимки и MP4-запись экрана, без аккаунта и сети. Android 10+ (API29), Kotlin UI/захват и Tesseract JNI: OCR-библиотека 4.9.0 проверена на наличии `armeabi-v7a`, `arm64-v8a`, `x86`, `x86_64` в AAR. Один APK включает все четыре ABI. Target/compile SDK35.

## Сборка

Нужны JDK17 или21 и Android SDK с `platforms;android-35`, `build-tools;35.0.0` и `platform-tools`.

```sh
export ANDROID_HOME=/path/to/android-sdk
./gradlew --no-daemon :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Отладочный APK: `app/build/outputs/apk/debug/app-debug.apk`. Он подписан стандартным debug-ключом сборочной машины; production подпись и публикация в магазине отдельно.

В wrapper включены официальные Gradle8.9 wrapper scripts/JAR из `gradle/gradle` tag `v8.9.0`; Gradle дистрибутив загружается с services.gradle.org. AGP8.7.3, Kotlin2.0.21, Tesseract4Android4.9.0 (JitPack). Build cache и `local.properties` не входят в Git.

## Использование

1. Выберите «Снимок» или «Запись». Система запросит разрешение и источник; для каждой сессии требуется новое согласие.
2. Снимок откроется в редакторе (если Android ограничил открытие из фона — нажмите уведомление «Снимок готов»). «Область» обрезает результат, остальные инструменты добавляют пометки. PNG/JPEG/WebP — выбор на главной.
3. Для видео выберите звук, размер, битрейт, FPS и MP4/H264/AAC либо WebM/VP8/Opus. «Без звука» не создаёт аудиодорожку. «Звук устройства» использует настоящий AudioPlaybackCapture; микрофон отдельный, «Устройство и микрофон» смешивает PCM перед AAC/Opus.
4. Управление записью доступно в постоянном уведомлении и в главном окне. Для плавающей мини-панели нужно отдельное разрешение «Поверх других приложений», предлагаемое при включении опции. На панели: таймер, «Пауза»/«Продолжить» и «Стоп»; панель можно перемещать за заголовок. На некоторых системах overlay попадает в запись — Android не предоставляет универсального исключения своей панели из полного экрана.
5. «Выбрать область видео» делает отдельный снимок для выделения прямоугольника. При записи потребуется новое согласие MediaProjection, а EGL SurfaceTexture compositor записывает только выбранный прямоугольник. Камера встраивается этим же compositor прямо в видео: выбор передней/основной камеры, размера, угла и круглой/прямоугольной формы.
6. OCR «Текст OCR» работает локально в редакторе: bundled `tessdata_fast` 4.1.0 русский+английский; сеть и ключи не требуются. Результат можно отредактировать/скопировать.
7. В истории видео доступна локальная «Обрезать видео»; начало привязывается к предыдущему ключевому кадру, исходник сохраняется.
8. Результаты по умолчанию — `Изображения/Кадролов` и `Фильмы/Кадролов`. «Выбрать папку» использует системный Storage Access Framework, доступ запоминается. «Мои файлы» открывает локальную историю и системную отправку файла.

## Реальные ограничения

- Приложения и рабочие профили могут запрещать снимки/звук. DRM и запреты не обходятся. CaptureService завершает захват при отзыве MediaProjection.
- У Android нет разрешённого обычному приложению API глобальных касаний/кнопок мыши в чужих окнах и универсального скрытия курсора. Поэтому нет фиктивных переключателей. Собственные AccessibilityService/скрытый сбор ввода не используются.
- Область снимка выбирается в редакторе после захвата. Сохранённый прямоугольник видео относителен к системно выбранному источнику; если выбирается другое приложение, проверьте область заново.
- MP4/H264/AAC и WebM/VP8/Opus требуют соответствующих аппаратных/системных кодировщиков; отсутствие выбранного кодировщика является явной ошибкой. MKV не предоставляется, так как Android MediaMuxer не поддерживает его.
- Поворот/изменение размера уже захватываемого контента останавливает текущую запись и требует новой сессии, вместо повторного использования одноразового токена Android14.
- После сбоя незакрытый MP4 может не восстановиться. «Незавершённые записи» предлагает только проверенное сохранение временного контейнера; если индекс MP4 отсутствует, программа честно сообщает об ошибке.
- Во время работы редактора исходник находится только в приватном cache; после успешного экспорта/отказа он удаляется. «Закрыть» заменяет пиксели непрозрачным цветом; экспорт — сведённый bitmap без слоёв. Пикселизация не гарантирует конфиденциальность текста.

## Проверки

`tests/TimelineSmoke.java` — автономная проверка pause clock стандартным JDK. JUnit `RecordingTimelineTest` проверяет паузу, повторную паузу и отрицательное время. `FrameScheduleTest` проверяет независимый вывод статичного источника, точный финальный кадр, паузу и отсутствие двойного пропуска при округлении таймера; `StaticFrameSmoke` — автономный red/green smoke этой регрессии. Реальные MediaProjection, кодировщики, воспроизводимость MP4, overlay и звук необходимо проверять на Android-устройстве; наличие исходников и успешная сборка не являются такой проверкой.

Официальные API: [MediaProjection](https://developer.android.com/media/grow/media-projection), [AudioPlaybackCapture](https://developer.android.com/media/platform/av-capture).

## Зависимости и лицензии

Модели `eng.traineddata` и `rus.traineddata` взяты из официального `tesseract-ocr/tessdata_fast` tag4.1.0, лицензия Apache2.0. Tesseract4Android4.9.0 — Apache2.0 с собственными сторонними библиотеками; лицензии приложены в `licenses/`. SHA256 моделей, AAR и состав ABI записаны в `licenses/dependency-provenance.json`. Пользовательские файлы в Git не включаются.

## Быстрый доступ, иконки и мини-панель

Инструменты редактора — собственные векторные иконки с русскими accessibility-подписями и tooltip. После выделения области рядом появляется компактная панель стрелка/рамка/овал/текст/непрозрачное закрытие/сохранение. Полная панель инструментов остаётся доступна прокруткой.

«Готовить быстрый доступ после перезагрузки» по умолчанию выключено. При включении BootReceiver только размещает уведомление с действиями «Снимок»/«Запись». Камера, микрофон и MediaProjection никогда не запускаются из boot receiver, и для каждого захвата остаётся системное согласие. При отключении уведомление удаляется. Если уведомления запрещены, интерфейс предлагает системные настройки. На аппаратной клавиатуре Ctrl+Alt+S/Ctrl+Alt+R действуют только внутри открытого Кадролова; глобальные сочетания Android приложению не предоставлены.

Подготовка записи показывает все выбранные параметры и место сохранения перед системным выбором источника. После согласия — трёхсекундная задержка. Временное видео сначала записывается в приватный cache и затем копируется в выбранную папку; на время экспорта нужно место для обеих копий.

## Выбор устройства микрофона

В настройках записи есть список «Микрофон для записи»: системный микрофон либо конкретный вход с именем, типом и Android ID (встроенный, гарнитура, USB, Bluetooth и другие физические входы). Выбор запоминается. Его применяют только режимы «Микрофон» и «Устройство и микрофон»; AudioPlaybackCapture системного звука остаётся отдельным.

Для выбранного входа вызывается AudioRecord.setPreferredDevice, проверяется подтверждение и фактический маршрут до передачи PCM кодировщику. Отключённое сохранённое устройство остаётся в списке с пометкой «недоступен» и не заменяется системным микрофоном автоматически. При исчезновении выбранного входа или смене маршрута запись останавливается, доступная часть сохраняется и появляется объяснение. После перезагрузки или переподключения Android может выдать устройству новый ID — тогда нужно выбрать его заново. Системный вариант явно оставляет выбор маршрута самой ОС.

Проверка переключения физического USB/Bluetooth/встроенного микрофона требует реального Android-устройства. Перечисление устройств и успешная сборка сами по себе её не доказывают.
