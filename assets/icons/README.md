# Kadrolov application icon

Original screenshot-corner frame and mouse-pointer artwork in the application's warm orange, cream and charcoal palette. Contains no lettering or external artwork.

- `kadrolov.svg`: editable 1024-unit master.
- `kadrolov-1024.png`: transparent RGBA master render.
- `kadrolov-256.png`: preview; other PNG files support small desktop UI sizes.
- `kadrolov.icns`: macOS bundle icon, generated by Apple's `iconutil`.
- `kadrolov.ico`: Windows icon containing PNG-backed 16, 32, 48, 64, 128 and 256-pixel images.
- `Kadrolov.iconset/`: standard Apple iconset source at normal and Retina resolutions.

Reproduce on macOS from the repository root:

```sh
swift scripts/render-icon.swift
```

The renderer uses AppKit vector drawing and Foundation, with no package install or external service. SVG and bitmap coordinates are maintained together in the renderer. Android's `ic_launcher.xml` uses the same glyph with additional launcher-safe inset and a full-bleed orange background.
