# Кадролов Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Локальное приложение снимков/видеозаписи с русским UI и мини-панелью, исходниками и сборками на GitHub.

**Architecture:** Qt Widgets desktop UI и редактор отделены от Recorder и нативных backend. ScreenCaptureKit helper обслуживает macOS; X11/Windows capture используют свои доступные backend. Android — независимое Kotlin приложение с MediaProjection.

**Tech Stack:** C++17, Qt5/6, CMake, Swift/AVFoundation/ScreenCaptureKit, FFmpeg, Kotlin/Gradle.

**Spec:** ../specs/2026-10-26-kadrolov-design.md; согласованные поправки локального режима приоритетны.

## Global Constraints
- Только устройство; никаких серверов, аккаунтов или облака.
- Русский UI, независимые звук/курсор/клики, папки/качество/размер/формат.
- Мини-панель: Стоп, Пауза, Продолжить, таймер.
- Windows/Linux x64/ARM64/legacy32; macOS ARM64/x64; Android JVM APK. Проверенное отделять от целевого.
- Тяжёлые сборки последовательно на M1/16GB; не менять чужие файлы.

## Review Focus
- Отказ в разрешении или исчезнувший источник: не захватывать другой экран молча.
- Пауза: не увеличивать длительность и не терять синхронизацию.
- Экспорт скрытой области: не возвращать исходные пиксели/слои.
- Неуспех кодировщика/нет места: не объявлять файл готовым.
- UI не перекрывает выход и управление при DPI/узком экране.
