# Проверка 0.1.0

Этот файл обновляется по фактическим результатам. Дата начала: 26–27 октября 2026.

## Подтверждено на macOS 15.6.1 / Apple M1

- Сборка Qt desktop и ScreenCaptureKit helper ARM64.
- QtTest: валидация параметров, безопасная передача пути кодировщику, отсутствие аудио в режиме тишины; редактор — непрозрачное закрытие/undo/redo, обрезка, изменение текста.
- Native helper: реальные записи none/system/mic/both, пауза/продолжение, FFprobe и полное декодирование.
- Recorder integration: start → recording → pause → resume → finalize → completed, корректный MP4.
- SCScreenshotManager получает содержимое открытых окон; отказ Qt screenshot был найден в GUI и маршрут заменён.
- Vision OCR распознал искусственное изображение с кириллицей/латиницей.
- Нативное смешивание двух AAC дорожек: один итоговый аудиопоток, оба тестовых тона; H264 видеопакеты сохранены без перекодирования.

## Ещё проверяется

- Полный GUI сценарий новой сборки и мини-панели.
- Android unit/lint/APK, runtime на устройстве.
- CI остальных платформ и архитектур.

## Ограничения проверки

Windows, Linux/Wayland и Android аппаратно на этом Mac пока не проверялись. Нельзя считать эти проверки пройденными по одному наличию CI или исходников. Доступ к DRM/запретившим захват приложениям не обходится. Нет 32-bit macOS и ARM32 Windows.
