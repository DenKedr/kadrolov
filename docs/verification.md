# Проверка выпусков Кадролова

Проверки 26–27 октября 2026. Исходники опубликованы в [DenKedr/kadrolov](https://github.com/DenKedr/kadrolov); журнал платформенных сборок — [GitHub Actions](https://github.com/DenKedr/kadrolov/actions).

## Подтверждено на macOS 15.6.1 / Apple M1

- ARM64 сборка Qt desktop и ScreenCaptureKit helper, упаковка Qt и проверка целостности подписи `codesign --verify --deep --strict`.
- QtTest: валидация параметров записи, пути с пробелами, отсутствие аудио в режиме тишины; редактор — непрозрачное закрытие, undo/redo, изменение текста, обрезка, выбор/изменение области, экспорт без затемнения и рамки. Путь перетаскивания тестируется через QWindow на Qt5/6.
- Native helper: реальные записи none/system/mic/both, пауза/продолжение, FFprobe и полное декодирование.
- Qt Recorder integration: start → recording → pause → resume → finalize → completed; итоговый MP4.
- SCScreenshotManager получает содержимое открытых окон; standalone GUI открыл полноэкранный редактор с полученным снимком.
- Vision OCR распознал искусственное изображение с кириллицей/латиницей.
- Native mix двух AAC: один итоговый аудиопоток, оба тона 440/880 Гц; H264 пакеты сохранены без перекодирования.
- GUI настроек: переключатель автозапуска создал валидный LaunchAgent с точным путём приложения и --background; отключение удалило запись. Возвращён OFF. Интерфейс показывает отдельные глобальные сочетания снимка/видео.
- GUI: выделение области, всплывающая панель, стрелка и текст, Save As PNG проверены. Исправлены маршрутизация accessibility и смещение панели; регрессионные тесты экспорта проверяют отсутствие выделения/каретки.
- Native sparse regression: статичное окно, 6 с записи → 2 с пауза → 5 с записи, MP4 11.048 с и полное декодирование. Исправлена ошибка переноса ScreenCaptureKit timing/attachments, дававшая двойную длительность.
- Иконка рамки снимка с курсором включена в Qt resources, macOS ICNS, Windows ICO/RC и Android launcher.

## Границы проверки

Ручной GUI сценарий полностью пройден: выделение, стрелка, русский текст, сохранение PNG; запись области, пауза, продолжение, стоп и появление MP4 в истории. Итоговый H264600×400,42.573с полностью декодируется. Qt Recorder regression 6с→пауза2с→5с завершилась в11.238с; статичный native case —11.048с. Исправленный экспорт выделенного текста проверяется pixel-perfect тестом с восстановлением состояния редактирования.

Не проверены на физических устройствах: Windows, Linux/Wayland, Android, macOS Intel/13/14; камера и несколько мониторов. Эмулятор Android не заменяет проверку микрофона/системного звука на телефоне. Ограничения DRM и приложений, запретивших захват, не обходятся. Нет32-bit macOS и ARM32 Windows. Две кнопки мыши/отдельный тихий режим пока отсутствуют; отдельный picker окна подключён только macOS. Подробности — [матрица](features.csv).

## Разрешения и подпись Mac

У локальных ad-hoc сборок смена кода меняет designated requirement, поэтому старое включённое разрешение может не соответствовать новой программе. Причина установлена через tccd/codesign; [диагностика](../native/macos/tests/tcc-diagnosis.md). Для локальной проверки применена постоянная Apple Development identity; штатно обновлено только разрешение ScreenCapture самого Кадролова. Общие настройки защиты и разрешения других приложений не изменялись. Публичные CI пакеты — ad-hoc и пока без нотарификации Apple.

## 0.1.1: закрытие и скрытый автозапуск

Реализовано отдельное завершение «Выход», а крестик скрывает окно, сохраняя запись и горячие клавиши. Повторный запуск использует локальный IPC текущего пользователя и показывает прежнее окно; повторный `--background` не открывает его. Это локальный канал без TCP/внешнего сервера.

На Mac ARM64 собраны и прошли3/3 CTest suites; lifecycle содержит8 проверок, включая настоящий дочерний QApplication::exec, скрытую стартовую активацию, последующее открытие, повторный запуск и реальное завершение процесса. Системное завершение сеанса не перехватывается обычным режимом «закрыть в фон». Сам компьютер для проверки не перезагружался.

Android0.1.1/versionCode2: сборка release,6JUnit,lint и компиляция усиленного runtime-теста прошли локально. Тест завершает Activity во время записи, проверяет продолжающийся foreground service/уведомление, открывает Activity заново и проверяет паузу/продолжение/итоговый MP4. Эмулятор API35 выполнил оба runtime-теста: 2 passed, 0 failures/errors/skips; в том числе уничтожение Activity во время записи, продолжающийся foreground service и читаемый MP4. [Запуск](https://github.com/DenKedr/kadrolov/actions/runs/40412804523).

На реальном Mac повторно проверены переключатель автозапуска ON/OFF, точный аргумент `--background` в LaunchAgent, скрытый запуск без окна, сохранение процесса после крестика, восстановление прежнего окна повторным запуском без дубликата и полное завершение через Cmd+Q. Автозапуск после проверки возвращён в OFF.

Светлая тема0.1.1: на Mac визуально проверены светлые страницы и контрастные текст/поля/кнопки, видимые стрелки combo/spinbox, рамка выключенного checkbox и галочка включённого. Исправлено наследование тёмной системной палитры; тёмные цвета сохранены. Android light-only палитра собрана,6unit иlint безошибок; отдельного визуального испытания на телефоне нет.

## 0.1.2: тёмная тема Windows

28 октября 2026. На светлой системной палитре Windows тёмная тема оставляла белые viewport/страницы и полоску меню, а текст становился светлым. Исправлена причина: тёмная палитра теперь явно задаёт роли фона/текста/выделения/disabled и поверхности scroll/stack/menu. Добавлены контрастные стрелки списков и spinbox в ресурсах Qt. Светлые цвета сохранены; проверены повторные переключения.

Regression сначала воспроизвёл проблему на прежнем коде с Fusion и принудительно светлой палитрой. Исправленный код прошёл3 локальных CTest suites на Mac ARM64 и [все3 Windows задания CI](https://github.com/DenKedr/kadrolov/actions/runs/40717503752): x64/ARM64 Qt6.8.3 и x86 Qt5.15.2. В каждом пройдены recording_plan/editor/lifecycle, включая9 случаев lifecycle. Сохранены7 PNG на архитектуру: четыре вкладки в тёмной теме и переходы dark/light. Проверены фон viewport, меню, подписи, стрелки и checkbox. EXE прошли установку/удаление. Изображения получены от Qt на Windows в CI; рабочий стол пользователя не захватывался. Независимый узкий обзор исходников не нашёл новых P1/P2.

[Опубликован Windows-выпуск0.1.2](https://github.com/DenKedr/kadrolov/releases/tag/v0.1.2), исходники `e153c609e79241874cde19015abb45131ea1939d`: EXE3,portable ZIP3, пример окна, манифест и SHA256SUMS. Все9 файлов проверены по удалённому размеру и SHA-256. Это обновление Windows; прежние установщики остальных платформ остаются в0.1.1. Аппаратный захват/звук на Windows повторно не проверялся: изменение касается интерфейса. Перед обновлением нужно полностью завершить старый Кадролов через «Выход», поскольку крестик оставляет его в фоне.
